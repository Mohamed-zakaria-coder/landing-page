# 🚀 **Landing Page Project**

A sleek and responsive **React-based landing page** designed for modern brands and startups.  
Originally bootstrapped with **Create React App**, this project has evolved with smooth interactions and a cleaner component architecture.

---

## ✨ **Features**

- 🌐 **Fully Responsive** — Optimized for both desktop and mobile devices  
- 🎛️ **Interactive FAQ Accordion** — Smooth expand/collapse animation  
- 🧩 **Reusable Components** — Modular, maintainable structure  
- 🎨 **Modern Aesthetic** — Powered by **Lucide React** icons  
- 💅 **Clean Custom Styling** — Handcrafted **CSS3** for simplicity and clarity  

---

## 🛠️ **Tech Stack**

| Technology | Purpose |
|-------------|----------|
| ⚛️ [React](https://reactjs.org/) | UI library for building components |
| 💎 [Lucide React](https://lucide.dev/) | Elegant, lightweight icons |
| 🎨 [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS) | Custom styling and animations |

## ⚙️ **Installation**

# 1️⃣ Clone this repository
git clone https://github.com/mohamed-zakaria-coder/landing-page.git

# 2️⃣ Move into the project directory
cd landing-page

# 3️⃣ Install dependencies
npm install

# 4️⃣ Start the development server
